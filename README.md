# Phishing-Awareness-Analysis-Triage-Toolkit
This document serves as a comprehensive guide for identifying and handling suspected phishing attempts. It features a non-expert triage checklist to spot psychological triggers and technical disguises, alongside a Standard Operating Procedure (SOP) for analyzing email headers and deceptive URLs.


# DecodeLabs Project 3: Phishing Awareness Analysis & Triage Toolkit

## 📌 Project Overview
This repository contains the deliverables for **Project 3** of the Decode Labs internship. The project focuses on Phishing Awareness Analysis, establishing a structured triage toolkit, and defining standard operating procedures (SOPs) for identifying, analyzing, and mitigating social engineering threats[cite: 1].

## 🎯 Key Deliverables Included
*   **Phishing Triage Checklist**: A practical guide for non-expert personnel to spot sender anomalies, psychological triggers (authority, urgency, fear/greed), link disguises, and unsafe attachment types[cite: 1].
*   **Header & URL Analysis SOP**: Step-by-step methodology for parsing email headers to catch display name spoofing and reading nested subdomains using right-to-left analysis.
*   **Incoming Threat Decision Tree**: An actionable "Pause, Verify, Report" workflow mapped to three clear outcomes: **Close**, **Warn User**, or **Block & Escalate**.
*   **Phishing Simulations & Analysis**: Detailed breakdowns of three distinct threat vectors:
    1. *Business Email Compromise (Whaling)*[cite: 1]
    2. *Credential Harvesting via SaaS Impersonation*[cite: 1]
    3. *Multi-Channel Callback Phishing (TOAD)*[cite: 1]
